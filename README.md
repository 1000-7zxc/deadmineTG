# DeadMine Telegram Support Bot

Telegram бот с системой тикетов для технической поддержки.

## Функционал

- 📋 Просмотр активных тикетов
- 📧 Создание новых тикетов
- 💬 Обмен сообщениями между пользователем и администрацией
- ✅ Закрытие тикетов администраторами
- 🔔 Уведомления для админов о новых тикетах

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/1000-7zxc/deadmineTG.git
cd deadmineTG
```

2. Установите зависимости:
```bash
npm install
```

3. Создайте `.env` файл на основе `.env.example`:
```bash
cp .env.example .env
```

4. Заполните `.env` файл:
   - `BOT_TOKEN` - токен бота от @BotFather
   - `ADMIN_CHAT_ID` - ID группы/канала для админов
   - `ADMIN_IDS` - ID админов через запятую

## Запуск

### Локально
```bash
npm start
```

### С автоперезагрузкой (разработка)
```bash
npm run dev
```

## Как получить ID

### Bot Token
1. Напишите @BotFather в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен

### Chat ID
1. Добавьте бота в группу
2. Напишите @userinfobot
3. Перешлите любое сообщение из группы боту
4. Он покажет ID группы

### User ID
1. Напишите @userinfobot
2. Отправьте `/start`
3. Бот покажет ваш ID

## Использование

### Для пользователей:
1. Нажмите "📧 Создать новый тикет"
2. Опишите вашу проблему
3. Ждите ответа от администрации

### Для админов:
1. Получите уведомление о новом тикете
2. Нажмите "✉️ Ответить"
3. Отправьте ваш ответ
4. Пользователь получит сообщение с префиксом "Админ: ..."
