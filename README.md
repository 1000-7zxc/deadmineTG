# DeadMine Telegram Support Bot

Telegram бот с системой тикетов для технической поддержки.

## Функционал

### Для пользователей:
- 📋 Просмотр своих тикетов
- 📧 Создание новых тикетов
- 💬 Отправка сообщений в тикет
- 🔔 Получение ответов от админов с префиксом "Админ: сообщение"

### Для админов:
- 📋 Просмотр всех тикетов (открытых и закрытых)
- 📂 Открытие тикета и просмотр переписки
- ✉️ Ответ на сообщения пользователей
- ✅ Закрытие тикетов
- 📊 Статистика по тикетам
- 🔔 Уведомления о новых тикетах и сообщениях

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/1000-7zxc/deadmineTG.git
cd deadmineTG
```

2. Установите зависимости:
```bash
npm install
```

3. Создайте `.env` файл на основе `.env.example`:
```bash
cp .env.example .env
```

4. Заполните `.env` файл:
   - `BOT_TOKEN` - токен бота от @BotFather
   - `ADMIN_CHAT_ID` - ID группы/канала для админов
   - `ADMIN_IDS` - ID админов через запятую

## Запуск

### Локально
```bash
npm start
```

### С автоперезагрузкой (разработка)
```bash
npm run dev
```

1. Создайте новый проект на Railway
2. Подключите GitHub репозиторий
3. Добавьте переменные окружения в настройках
4. Railway автоматически задеплоит бота

## Как получить ID

### Bot Token
1. Напишите @BotFather в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен

### User ID (для ADMIN_IDS)
1. Напишите @userinfobot
2. Отправьте `/start`
3. Бот покажет ваш ID

## Использование

### Для пользователей:
1. Откройте бота
2. Нажмите "📧 Создать новый тикет"
3. Опишите вашу проблему
4. Ждите ответа от администрации

### Для админов:
1. Откройте бота (вы увидите админ-панель)
2. Нажмите "📋 Все тикеты"
3. Выберите тикет из списка
4. Просмотрите переписку
5. Нажмите "✉️ Ответить" и отправьте сообщение
6. Пользователь получит ваш ответ с префиксом "Админ: ..."
7. При необходимости закройте тикет кнопкой "✅ Закрыть"
