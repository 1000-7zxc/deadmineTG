# Инструкция по настройке бота на Railway

## 1. Создание базы данных PostgreSQL

1. В Railway нажмите "New" → "Database" → "Add PostgreSQL"
2. После создания скопируйте `DATABASE_URL` из вкладки "Variables"

## 2. Настройка переменных окружения

В Railway добавьте следующие переменные:

```
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_IDS=ваш_id,id_другого_админа
DATABASE_URL=postgresql://... (автоматически добавится при подключении БД)
NODE_ENV=production
```

## 3. Подключение к GitHub

1. Подключите репозиторий `1000-7zxc/deadmineTG`
2. Railway автоматически задеплоит бота

## Особенности

✅ **Автоочистка БД**: Тикеты старше 3 суток автоматически удаляются каждые 6 часов
✅ **Лимит тикетов**: Один пользователь может создать максимум 3 активных тикета
✅ **Поддержка медиа**: Фото, видео, документы (до 30мб), GIF, стикеры
✅ **История тикетов**: Нумерованные сообщения с временем и ролью

## Получение ID

### Bot Token
1. Напишите @BotFather
2. `/newbot` → следуйте инструкциям
3. Скопируйте токен

### User ID (для ADMIN_IDS)
1. Напишите @userinfobot
2. `/start`
3. Скопируйте ваш ID

## Структура БД

### Таблица `tickets`
- `id` - ID тикета
- `user_id` - ID пользователя
- `username` - Имя пользователя
- `status` - Статус (Открыт/Закрыт)
- `created_at` - Время создания

### Таблица `messages`
- `id` - ID сообщения
- `ticket_id` - ID тикета
- `text` - Текст сообщения
- `media_type` - Тип медиа (photo/video/document/animation/sticker)
- `media_file_id` - File ID для Telegram
- `is_admin` - Админ или пользователь
- `timestamp` - Время отправки
